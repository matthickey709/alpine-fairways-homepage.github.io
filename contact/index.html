Reporting a bug

If something broke, these details help us fix it quickly:

  • Which app, and the page or screen you were on.
  • What you expected to happen, and what happened instead.
  • Your device and browser, for example "iPhone, Safari" or "Windows laptop, Chrome".
  • For Game Night Trivia, the game code if you have it.
  • A screenshot, if you can take one.
